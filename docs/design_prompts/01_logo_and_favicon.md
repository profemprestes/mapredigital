# Prompts: Logotipo y Favicon (Mapre Digital)

Utiliza estos prompts de IA para generar propuestas de logotipo y variaciones del mismo (imagotipo, favicon, etc.) para "Mapre Digital", basados en el "Contexto Global de Marca" (`00_global_brand_context.md`).

---

## 1. Logo Principal (Imagotipo: Símbolo + Texto)

**Prompt (DALL-E 3 / Midjourney):**

> "Diseña un logotipo principal moderno, tecnológico y minimalista para una agencia de desarrollo web y posicionamiento SEO llamada 'Mapre Digital'. El diseño debe ser un imagotipo (un símbolo abstracto a la izquierda y el nombre de la empresa a la derecha en tipografía sin serif, limpia y legible).
>
> El símbolo debe evocar conceptos de: crecimiento digital, tecnología, conexiones o el 'siguiente nivel' (como nodos entrelazados, flechas sutiles apuntando hacia arriba y a la derecha, o una letra 'M' modernizada).
>
> Paleta de colores estricta: Usa Azul Marino Profundo (#1D3B58) para el texto y las formas principales del símbolo, y añade detalles o un gradiente sutil en Celeste Claro (#ADD8E6) para denotar tecnología. El fondo debe ser totalmente blanco (#FFFFFF). Estilo visual: Flat vector design, limpio, flat logo corporativo de alta gama, vector art, Dribbble style."

## 2. Favicon / Símbolo Aislado (Para la pestaña del navegador, RRSS)

**Prompt (DALL-E 3 / Midjourney):**

> "Crea un 'Favicon' (icono de aplicación o símbolo aislado) para la marca 'Mapre Digital', una agencia tech de software y SEO. No incluyas texto, solo el símbolo gráfico.
>
> Debe ser un símbolo altamente reconocible, audaz y geométrico, diseñado para verse claramente en tamaños muy pequeños (como la pestaña del navegador). Utiliza una estructura cuadrada perfecta (aspect ratio 1:1). Puede ser una abstracción geométrica de la letra 'M' fusionada con un gráfico de crecimiento, un nodo digital o un circuito.
>
> Colores: El fondo debe ser transparente o blanco (#FFFFFF). El icono en sí debe combinar los colores Azul Marino Oscuro (#1D3B58) y detalles en Celeste Brillante (#ADD8E6), con tal vez un pequeñísimo acento en Rojo Vivo (#FF4136) para darle carácter. Estilo visual: Minimalist app icon, flat vector logo, clean geometry. --ar 1:1"

## 3. Logo en Versión Negativa (Para fondos oscuros / Dark Mode UI)

**Prompt (DALL-E 3 / Midjourney):**

> "Genera una versión alternativa de logotipo (imagotipo) para la agencia 'Mapre Digital', optimizado para ser usado sobre fondos oscuros (Dark Mode).
>
> El fondo de la imagen debe ser un bloque sólido de Azul Marino Profundo (#1D3B58). El texto 'Mapre Digital' debe ser color Blanco Puro (#FFFFFF) o Gris Muy Claro (#F9F9F9). El símbolo abstracto que acompaña al texto debe estar en Celeste Brillante (#ADD8E6) o Blanco, creando un alto contraste tecnológico.
>
> El diseño general transmite seguridad cibernética, software de alta calidad, innovación constante y posicionamiento web. Estilo: Flat vector logo, modern tech branding, dark mode logo, clean and sharp."
