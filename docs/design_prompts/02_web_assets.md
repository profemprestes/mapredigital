# Prompts: Activos Web y UI (Mapre Digital)

Utiliza estos prompts de IA para generar los fondos, banners y recursos ilustrativos necesarios para construir las secciones del sitio web (Hero section, Tarjetas de Servicios, etc.) de "Mapre Digital".

---

## 1. Fondo Hero Section (Página de Inicio)

**Prompt (Midjourney v6.0 / DALL-E 3):**

> "Crea un fondo panorámico abstracto, tecnológico e hiperrealista para la sección principal (Hero Section) de la web de la agencia de software y SEO 'Mapre Digital'.
>
> La composición debe dominar el color Azul Marino Profundo (#1D3B58) en el fondo, simulando un espacio digital profundo u oscuro (Dark Mode UI background). Sobre este fondo, añade sutiles líneas de conexión digital, redes neuronales abstractas, ondas tecnológicas suaves o partículas flotantes iluminadas en color Celeste brillante (#ADD8E6) y algún mínimo destello en Rojo Vivo (#FF4136).
>
> El lado izquierdo de la imagen debe ser más limpio, oscuro y vacío (espacio negativo sustancial) para poder superponer un gran texto en color blanco con el titular 'Impulsamos tu Negocio al Siguiente Nivel Digital'. La carga visual (las partículas/conexiones) debe concentrarse hacia la derecha de la imagen.
>
> Estilo visual: Abstract tech background, glassmorphism UI elements, cinematic lighting, sleek corporate tech style. --ar 16:9 --style raw"

## 2. Ilustración 3D para Servicio: Posicionamiento Web (SEO)

*(Ideal para usar dentro de una Card o sección descriptiva del servicio)*

**Prompt (Midjourney / DALL-E 3):**

> "Genera una ilustración 3D isométrica, minimalista y limpia (estilo 'Clay render' o '3D UI Icon') para representar el servicio de 'Posicionamiento Web SEO Estratégico' de una agencia digital.
>
> La escena podría mostrar un cohete despegando de una pantalla holográfica o un gráfico de barras ascendente envuelto por una lupa de búsqueda.
>
> Paleta de colores: El fondo debe ser un Gris muy claro / Blanco Humo (#F9F9F9) para simular espacio de web limpio. Los elementos 3D principales deben ser Azul Marino (#1D3B58) y Celeste (#ADD8E6), con un detalle destacado (como el fuego del cohete o la barra más alta) en Rojo Vivo (#FF4136).
>
> Estilo: Modern 3D isometric illustration, soft studio lighting, clean tech aesthetic, white background, high-end corporate graphics. --ar 1:1"

## 3. Ilustración 3D para Servicio: Herramientas a Medida (Software)

**Prompt (Midjourney / DALL-E 3):**

> "Crea una ilustración 3D isométrica minimalista (estilo 'Clay render' o '3D UI Asset') para representar el 'Desarrollo de Herramientas Online a Medida' (SaaS, CRMs, calculadoras web).
>
> La composición debe mostrar piezas de rompecabezas ensamblándose en un engranaje tecnológico, ventanas de código flotantes y abstractas, o una interfaz de usuario limpia construyéndose capa por capa (glassmorphism).
>
> Utiliza la paleta corporativa: Fondo Blanco Humo (#F9F9F9), objetos 3D en Azul Marino (#1D3B58) y Celeste brillante (#ADD8E6), con pequeños detalles vibrantes en Rojo (#FF4136) para elementos interactivos como botones o notificaciones.
>
> Estilo: 3D modern isometric icon, software development concept, soft shadows, clean UI aesthetic, professional tech illustration. --ar 1:1"
